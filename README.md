# Accessible Form UI Component

## 🚀 Features
- **Form Progress Indicator:** Visual feedback on completion.
- **Accessibility First:** Semantic HTML, ARIA labels, and WCAG-compliant color contrast.
- **Interactive States:** Distinct focus rings for keyboard navigation.
- **Password Requirements Checklist:** Real-time feedback UI.
- **Responsive Design:** Works seamlessly on mobile and desktop.

## 🛠️ Accessibility Implementations
- Used `<label>` with the `for` attribute for all inputs.
- Implemented `aria-required` for screen reader clarity.
- Ensured a 4.5:1 color contrast ratio for readability.
- Added visible `:focus` states for users navigating via Tab key.
